# ND Prover - Automated Natural Deduction

An automated theorem prover and proof assistant for **Propositional Logic**, developed to solve and validate logic exercises from the *"Introduction to Logic in Philosophy"* course at **Humboldt-Universität zu Berlin** (Summer Semester 2024).

This project implements a complete pipeline for automated propositional logic proofs. It consists of several components that work together:
  - A parser that tokenizes user input and converts it into structured logical formulas.
  - An iterative backward solver that searches for a derivation from the given premises to the desired conclusion.
  - A proof checker that verifies the correctness of a generated derivation.
  - A formatter that simplifies proofs by removing duplicate and dead / non-referenced lines.

`User Input` -> `Parser` -> `Solver` -> `Checker` -> `Formatter` -> `Formal Proof`


### Computational Complexity
The problem of determining whether a conclusion follows from a set of premises in classical propositional logic is coNP-complete.

For a set of premises P and a conclusion C, a derivation exists if and only if P ⊨ C. This is equivalent to saying that there is no truth assignment under which all premises are true while the conclusion is false: P ⊨ C  ⟺  P∧¬C is unsatisfiable. Thus, the problem can be reduced to UNSAT, which is coNP-complete. Equivalently, its complement (determining whether there exists a counterexample assignment) is an instance of SAT and is NP-complete.
The solver handles the computational complexity through a backward-chaining search: starting from the conclusion, it determines which premises would be required to derive it and explores the corresponding inference rules. To prevent unbounded searches, the solver uses a maximum iteration limit (MAX_ITERATIONS) and a maximum nesting depth (MAX_NESTING_DEPTH).


## Propositional Logic

The project uses a formal language for [propositional logic](https://en.wikipedia.org/wiki/Propositional_logic#Language), referred to as PL throughout this documentation.
To form sentences / well-formed formulas in PL, we use Atomic expressions:

- Variables: "**P**", "**Q**", "**R**" as well as "**P<sub>1</sub>**", "**P<sub>2</sub>**", ..., "**Q<sub>1</sub>**", "**Q<sub>2</sub>**", ..., "**R<sub>1</sub>**", "**R<sub>2</sub>**", ...
- Connectives: "**&**" (and), "**v**" (or), "**¬**" (not), "**➜**" (implies), "**↔**" (equivalent)
- Punctuation: "**(**", "**)**"

This prover allows all uppercase letters as variables.

### Formation Rules for Well-Formed Formulas (wff):
- Every variable is a wff.
- If $\phi$ is a wff, then **$\neg\phi$** is a wff.
- If $\phi$ and $\psi$ are wffs, then **$(\phi\&\psi)$** is a wff.
- If $\phi$ and $\psi$ are wffs, then **$(\phi\vee\psi)$** is a wff.
- If $\phi$ and $\psi$ are wffs, then **$(\phi\to\psi)$** is a wff.
- If $\phi$ and $\psi$ are wffs, then **$(\phi\leftrightarrow\psi)$** is a wff.


## System of Natural Deduction

The System of Natural Deduction (ND) is used to determine whether a deductive argument is valid. 

* A **deductive argument** is a sequence of sentences in which one sentence (the conclusion) is intended to follow from the remaining sentences (the premises).
* A deductive argument is **valid** if and only if the conclusion follows from the set of premises.
* A sentence $S$ **follows** from a set of sentences $S_1, S_2, S_3, \dots$ if it is impossible for $S$ to be false while $S_1, S_2, S_3, \dots$ all are true.

Therefore, in a valid deductive argument, it is impossible for the conclusion to be false when the premises are true. In short: **If the conclusion can be derived in ND from the premises, the corresponding argument is valid.**

A Derivations consists of a sequence of lines. Each line is generated by applying one of the rules of natural deduction.
The top line contains the derivation relation to be shown: the premises, then the assertion symbol ⊦, and then the conclusion.
Each subsequent line contains 4 columns:
1. **Dependency Set:** A list of line-numbers of assumptions used to derive the current line.
2. **Line Number:** The sequential index of the line.
3. **Formula:** A well-formed formula of PL.
4. **Rule & References:** The rule applied and the lines it references.


A sentence ψ is derivable from the sentences ϕ<sub>1</sub> ... ϕ<sub>n</sub> if and only if there is a derivation in which:
1. ϕ<sub>1</sub> ... ϕ<sub>n</sub> appear as assumptions, and
2. the last line contains ψ as a sentence, and
3. the last line cites only the lines of ϕ<sub>1</sub> ... ϕ<sub>n</sub> as assumptions.

## Installation & Usage
This project requires Rust and Cargo.

Clone the repository and run the project with:

```bash
git clone <repository-url>
cd logic-prover
cargo run
```

Running Custom Arguments:

```bash
cargo run -- "(P -> Q1), P |- Q1"
```
Syntax Guide for CLI Inputs:
- Separate multiple premises with commas (,), and use |- to separate premises from the conclusion.

- Supported connectives in the CLI: & (and), v (or), ! (not), -> (implies), <-> (equivalent).

- Variables: Can be any alphanumeric string starting with a letter (e.g., P, Q1, FormulaA).

To run the test suite:

```bash
cargo test
```

# Full usecase example (from Argument to validity check)

1. Argument:

If the heater is on and the living room window is closed, the soil of the cactus and the house fern dries out extremely fast. However, the heater is on, but the soil does not dry out extremely fast. If the soil does not dry out extremely fast, the delicate house fern thrives. Furthermore, the house fern thrives if and only if it is watered regularly or the indoor humidity is consistently high. Finally, the indoor humidity is not consistently high.

Therefore, the house fern is watered regularly.


2. Normal Form

(P1) If the heater is on and the living room window is closed, the soil dries out extremely fast.

(P2) The heater is on, but the soil does not dry out extremely fast.

(P3) If the soil does not dry out extremely fast, the house fern thrives.

(P4) The house fern thrives if and only if it is watered regularly or the indoor humidity is consistently high.

(P5) The indoor humidity is not consistently high.

(C) The house fern is watered regularly. [(P1), (P2), (P3), (P4), (P5)]

2.1 Propositional Dictionary

$H$: The heater is on.

$W$: The living room window is closed.

$D$: The soil dries out extremely fast.

$F$: The house fern thrives.

$R$: The house fern is watered regularly.

$I$: The indoor humidity is consistently high.

3. Propositional Logic Argument Schema

(P1) ((H & W) → D)

(P2) (H & ¬D)

(P3) (¬D → F)

(P4) (F ↔ (R v I))

(P5) ¬I

(C) R [(P1), (P2), (P3), (P4), (P5)]

4. Deduction Check (Does the conclusion follow from the premises?)

|||    ((H & W) ➜ D), (H & ¬D), (¬D ➜ F), (F ↔ (R v I)), ¬I ⊦ R     ||
|:--:|:--:|:-----------------------------:|:----------------:|
| 1 |          (1) | ((H & W) ➜ D)       |   A*
| 2 |          (2) | (H & ¬D)             |   A*
| 3 |          (3) | (¬D ➜ F)            |   A*
| 4 |          (4) | (F ↔ (R v I))        |   A*
| 5 |          (5) | ¬I                   |   A*
| 2 |          (6) | ¬D                   |   &-B:2
| 2,3 |        (7) | F                    |   ➜-B:3,6
| 4 |          (8) | (F ➜ (R v I))       |    ↔-B:4
| 2,3,4 |      (9) | (R v I)              |   ➜-B:8,7
| 10 |         (10) | R                   |   A
| 11 |         (11) | I                   |   A
| 12 |         (12) | ¬R                  |   A
| 11,12 |      (13) | (I & ¬R)            |   &-E:11,12
| 11,12 |      (14) | I                   |   &-B:13
| 5,11,12 |    (15) | (I & ¬I)            |   &-E:14,5
| 5,11 |       (16) | ¬¬R                 |   ¬-E:12,15
| 5,11 |       (17) | R                   |   ¬-B:16
|   |          (18) | (R ➜ R)            |   ➜-E:10,10
| 5 |          (19) | (I ➜ R)            |   ➜-E:11,17
| 2,3,4,5 |    (20) | R                   |    v-B:9,18,19

In line 20 the prover derives R (our conclusion) while only depending on premises (P1 was not even used). Therefore a correct deduction was found and the argument is valid.
